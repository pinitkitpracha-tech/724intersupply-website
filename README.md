# 724intersupply website

เว็บไซต์ Company Profile บริษัท 724 อินเตอร์ซัพพลาย จำกัด (HTML + Tailwind CSS CDN) รองรับ 3 ภาษา ไทย / English / 繁體中文

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (ข้อความตั้งต้น + คำแปลในตัวแปร `I18N`) |
| `content.json` | ข้อความและรูปที่แก้ผ่านหน้า Admin (ระบบเขียนให้อัตโนมัติ) |
| `assets/` | รูปภาพ (`assets/uploads/` = รูปที่อัปโหลดผ่าน Admin) |
| `admin/admin.js` | ระบบ Admin (โหลดเฉพาะเมื่อเข้า `?admin`) |
| `admin/auth.json` | GitHub token ที่ถูกเข้ารหัสด้วยรหัสผ่าน (สร้างตอนตั้งค่าครั้งแรก) |

## ระบบ Admin
1. เข้า `https://โดเมนของคุณ/?admin`
2. ครั้งแรก: ใส่ GitHub fine-grained token (เฉพาะ repo นี้, สิทธิ์ Contents: Read and write) และตั้งรหัสผ่าน
3. ครั้งต่อไป: ใส่แค่รหัสผ่าน
4. คลิกข้อความเพื่อแก้ภาษาไทย (อังกฤษ/จีนแปลให้อัตโนมัติ แก้เพิ่มได้), คลิกรูปหรือเมนู "รูปภาพทั้งหมด" เพื่อเปลี่ยนรูป
5. กด "เผยแพร่" — เว็บจริงอัปเดตภายใน 1–2 นาที

ลืมรหัสผ่าน: กด "ตั้งค่าใหม่" แล้วใส่ token ใหม่

## ภาษา
ปุ่ม TH / EN / 中文 มุมขวาบน หรือเปิดลิงก์ `?lang=en`, `?lang=zh`
